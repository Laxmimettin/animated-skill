
# Animated Skill/Progress Bars

## 📌 Project Description
The Animated Skill/Progress Bars project is a responsive webpage that displays technical skills using animated progress bars. Each bar fills smoothly to a specified percentage when the skills section becomes visible on the screen.

## 🎯 Objective
To practice CSS animations, transitions, JavaScript DOM manipulation, and scroll detection using the Intersection Observer API.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## ✨ Features
- Displays six technical skills with labels and percentages.
- Smooth animated progress bars.
- Animation starts when the skills section enters the viewport.
- Animated percentage counters.
- Different colors for each skill.
- Replay Animation button to restart the animations.
- Responsive layout for desktop, tablet, and mobile devices.
- Reduced-motion accessibility support.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder.
3. Make sure all three files are in the same directory.
4. Open `index.html` in any modern web browser.
5. Scroll to the skills section to view the animations.
6. Click the Replay Animation button to restart them.

No additional installation or API key is required.
